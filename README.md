# おぼえトレ

ワーキングメモリ（作業記憶）を鍛えるトレーニングアプリ。「ことば」「すうじ（逆から入力）」「すうじ（合計を入力）」「Nバック」「デュアルNバック」「空間」「変化検出」「音・色」「ランダム」の9モードを提供する。React 19 + TypeScript + Vite + Tailwind CSS v4 製。トレーニング機能自体はバックエンドを持たないSPAで、全データはブラウザの`localStorage`に保存する（オプトインのリマインド通知機能のみ、最小限のサーバーサイド機構を使う）。全モード共通で経験値・プレイヤーレベル・今日のミッションなどのゲーミフィケーション要素を備える。PWA対応でホーム画面に追加してネイティブアプリ風に利用可能。UIは日本語/英語に対応（設定画面で切り替え可能。ことばモードは日本語の音韻に依存するため英語UIでは非表示）。

公開URL: https://oboetore.vercel.app/

## モード

### ことばモード

単語や短い文章を音声で聞き、逆から声に出して復唱する。

1. Web Speech API の `SpeechSynthesis` で問題文を読み上げる
2. 復唱のための時間を設ける（レベル別のカウントダウン表示）
3. Web Speech API の `SpeechRecognition` で逆から発話した内容を認識する
4. 正しい逆さ言葉と比較し、正解・不正解を判定する（レーベンシュタイン距離による許容判定あり）

`SpeechRecognition` は Chrome / Edge など一部のブラウザでのみ対応。非対応ブラウザでは警告表示のうえレベル選択を無効化する。

| レベル | 文字数 | 復唱の持ち時間 |
|---|---|---|
| 1 | 2〜4文字 | 4秒 |
| 2 | 4〜6文字 | 5秒 |
| 3 | 6〜8文字 | 6秒 |

### すうじモード（逆から入力/合計を入力）

表示された数字列を記憶し、「逆から入力」または「合計を入力」で回答する。ホーム画面では2つの独立したモードカードとして提供する。

| レベル | 桁数 |
|---|---|
| 1 | 3桁 |
| 2 | 5桁 |
| 3 | 7桁 |

### Nバックモード

3×3グリッドのマスを1つずつ光らせ、N個前の位置と一致するかどうかを判定する空間版Nバック課題。レベル1〜3でN=1〜3、出題数は10/20/30問から選択可能。信号検出理論に基づき採点する。

### デュアルNバックモード

3×3グリッドの位置と8種類の音（合成トーン）を同時に提示し、それぞれ独立に「位置一致」「音一致」を判定する高難度モード。レベル1〜3でN=1〜3、出題数は10/20/30問から選択可能。

### 空間モード

マスが順番に光るのを覚え、逆の順番でタップして答える視空間ワーキングメモリトレーニング（Corsi Block-Tapping Taskを参考）。

| レベル | グリッド | マス数 |
|---|---|---|
| 1 | 3×3 | 3 |
| 2 | 3×3 | 4 |
| 3 | 4×4 | 5 |

### 変化検出モード

一瞬表示される模様を覚え、白紙に戻った状態から元々塗りつぶされていたマスを選び直す視覚ワーキングメモリの再生課題（Luck & Vogel 1997の変化検出課題を参考にした再生版）。

| レベル | グリッド | 塗りつぶしマス数 |
|---|---|---|
| 1 | 4×4 | 4 |
| 2 | 4×4 | 6 |
| 3 | 5×5 | 8 |

### 音・色モード

4色のパッドが音とともに光る順番を覚え、同じ順にタップして再現する非言語性の聴覚ワーキングメモリトレーニング（Simon型）。

| レベル | 音数 |
|---|---|
| 1 | 3 |
| 2 | 4 |
| 3 | 5 |

### ランダムモード

すうじ（逆から入力/合計を入力）・空間・変化検出・音/色から1問ずつ、シャッフルした順で出題するミックス練習モード。出題数（3/5/7問）に加えて、出題するモードの種類も個別に選べる。

各モード・各レベル、3問（Nバック・デュアルNバックは10/20/30試行から選択、ランダムは3/5/7問から選択）1セットで出題する。

## ホーム画面

[ランダムモード]／[個別選択モード]／[今日のミッション]の3ボタンで構成する。「個別選択モード」から上記9モードのカードグリッド（ランダムモードを除く8モード）を選べる。「今日のミッション」は過去の正答率から自動選定した弱点モード・レベルに1日3セット挑戦するとXPがもらえる専用画面。

## その他の機能

- 実績（アチーブメント）システム：連続挑戦日数・累計セット数・プレイヤーLv到達・トレーニングスコアなどから動的に判定（24種類）
- 経験値・プレイヤーレベル：全モード共通。正解+10XP・全問正解セット+50XP・今日のミッション達成+100XP、レベルごとに必要XPが増加
- 効果音・BGM：いずれもWeb Audio APIによる完全プログラム生成（音声ファイル不使用）、それぞれ独立した音量スライダーで調整可能（BGMは既定OFF）
- 統計・履歴画面：モード別・レベル別の正答率、苦手分野、直近1ヶ月の学習カレンダー、トレーニングスコア（総合＋数字記憶/空間記憶/注意制御）
- 設定画面：テーマ（システム／ライト／ダーク）、音声合成の声・速度、効果音ON/OFF・音量、BGM ON/OFF・音量、1日の目標セット数
- リマインド通知（オプトイン）：その日1回もプレイしていない場合、指定した時刻にプッシュ通知でお知らせ（Vercel Serverless Functions + Redisを利用。詳細は[DEPLOYMENT.md](DEPLOYMENT.md)）

## コマンド

- `npm run dev` — 開発サーバー起動（ポート5174固定）
- `npm run build` — 型チェック後に本番ビルド
- `npm run lint` — oxlint 実行
- `npm run preview` — 本番ビルドのプレビュー
- `npm run test` — Vitestでロジック層のテストを実行
- `npm run test:e2e` — Playwrightでブラウザ上のE2Eテストを実行（初回は`npx playwright install --with-deps chromium`が必要）
