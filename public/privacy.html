プライバシーポリシー

最終更新: 2026-08-01

逆復唱トレーニング（以下「本アプリ」）における、利用者情報の取り扱いについて説明します。

1. 本アプリの基本構造

本アプリはバックエンド（サーバー）を持たないSPA（Single Page Application）であり、利用者が入力・記録したデータはすべて利用者自身のブラウザのlocalStorageにのみ保存されます。運営者を含む第三者のサーバーへデータが送信されることはありません。

2. 保存するデータ

データ 内容 保存先
トレーニング履歴 モード・レベル・正答数・挑戦日時（最大200件） ブラウザのlocalStorage（gyaku-fukushou:history）
アプリ設定 テーマ、読み上げ速度・声、効果音ON/OFF、1日の目標セット数 ブラウザのlocalStorage（gyaku-fukushou:settings）

氏名・メールアドレス・位置情報など、個人を特定できる情報は収集・保存しません（本ページ末尾の開発者連絡先を除く）。

3. マイク（音声）の利用について

「ことばモード」では、復唱内容を判定するためにブラウザの音声認識機能（Web Speech API の SpeechRecognition）を利用します。

  • マイクの使用にあたっては、ブラウザから利用者に許可を求めるダイアログが表示されます。許可しない場合、ことばモードの音声認識機能は利用できません。
  • 本アプリ自体（開発者・運営者）が音声データを収集・保存・送信することはありません。
  • ただし、SpeechRecognition APIの実装はブラウザに依存し、Google Chrome等の一部ブラウザでは、音声データがブラウザベンダー（Google等）のサーバーに送信され音声認識処理が行われる場合があります。これはブラウザ自体の仕様であり、本アプリが制御できるものではありません。詳細は利用しているブラウザのプライバシーポリシーを参照してください。
  • 読み上げ機能（SpeechSynthesis）についても同様に、利用しているブラウザ・OSの音声合成エンジンに処理を委ねています。

4. Cookie・アクセス解析・広告

本アプリはCookieを使用せず、アクセス解析ツールや広告配信のトラッキングも組み込んでいません。

5. 第三者提供

利用者のデータを第三者に提供・共有することはありません（データがそもそも本アプリの外部に送信されないため）。

6. データの削除方法

保存されているデータを削除したい場合は、ブラウザの設定からサイトデータ（localStorage）を削除することで、本アプリが保存したすべてのデータを消去できます。アプリ内に一括削除の専用機能は現時点で用意していません。

7. デプロイ・ホスティング

本アプリはVercel上でホスティングされています。Vercelのインフラ経由でアクセスログ等が生じる可能性がありますが、これはホスティング事業者側の標準的な運用の範囲であり、本アプリが独自に収集するものではありません。
